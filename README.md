# 청년문화패스 통합앱 프로토타입

청년국가재정마스터 5기 21팀 · 청년문화예술패스 분석 보고서 후속 프로토타입.
신청, 지역·관심 분야 선택, 맞춤 공연 추천, 잔여 지원금 알림, 예매처 리디렉션, 이벤트·쿠폰, 만족도 조사를 한 앱에서 체험할 수 있습니다.

> 모든 공연·가격·쿠폰은 **예시 데이터**입니다.

## 실행
빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 로컬 서버를 실행하세요.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인 토큰(라이트/다크), 컴포넌트 스타일 |
| `data.js` | 지역, 분야, 제도 시나리오(2026/2027안), 공연·이벤트·쿠폰 예시 데이터 |
| `app.js` | 상태 관리와 화면 렌더링 (온보딩, 홈, 공연 찾기, 혜택, MY) |

## GitHub Pages 배포
1. 저장소를 만들어 push
2. Settings → Pages → Source를 **GitHub Actions**로 선택
3. `main`에 push하면 `.github/workflows/pages.yml`이 자동 배포

## 실서비스 전환 시 과제
- 예매처(인터파크/YES24) 공연·좌석·잔여석 데이터 연동 가능 여부 확인
- 포인트 잔액 조회 방식 (현재는 앱이 사용 내역을 직접 기록)
- 기한 알림은 데모 고정값(17일) → 발급일/7월 말 회수 규칙으로 계산
- 영화 관람 횟수 제한(수도권 2회/비수도권 5회) 표시
- 상태 저장(현재는 메모리, 새로고침 시 초기화) → localStorage 또는 서버

## 데이터 기준 (2026-10-12)
`data.js`의 공연·전시·영화는 2026년 10월 12일 기준으로 공개 자료(예매처 상품 페이지, 문화포털, 각 미술관·영화제 누리집, 박스오피스 집계)를 확인해 구성했습니다.
- `est:1` 표시가 있는 항목은 요금을 확인하지 못해 **예시가**를 넣은 것입니다(영화 14,000원, 서울시립미술관 5,000원 등).
- 예매처 매핑(인터파크/YES24)은 프로토타입용 가정이며, 일정·가격은 수시로 바뀌므로 `TODAY` 값과 함께 갱신이 필요합니다.
- 본인 인증(PASS·SMS 등)은 **화면 예시**이며 실제 인증 연동이 없습니다. 데모 인증번호는 `123456`입니다.

## 디자인 메모
- 서체: Noto Sans KR (Google Fonts) — 본문 15px, 행간 1.6
- 화면 전환: 탭·온보딩 단계 이동 시 페이드+슬라이드 (`prefers-reduced-motion` 설정 시 해제)
- 아이콘은 이모지 대신 인라인 SVG(`app.js`의 `IC`)
- 지역·가격 필터: 지역(전체/내 지역/전국 공통/시도별, 개수 표시), 가격(3만·7만·10만 원 이하, 가장 저렴한 좌석 기준)
- 본인 인증 단계에서 거주 지역을 함께 받고, 다음 단계에서 확인/변경하도록 연계

## 할인 권종(재관람·지역 할인) 처리
`data.js`의 좌석 항목 3번째 값(`{k, rg, c}`)이 있으면 **앱에서 바로 적용하지 않는 할인 권종**입니다.
- 목록·상세에 "예매처 확인 필요" 표시, 가격 필터(`minP`)는 정가 좌석 기준
- 상세에서 예매처 확인 순서(권종 선택·증빙·차액 가능성)를 보고 체크해야 이동 가능
- 예매 후에는 MY 사용내역에 "확인 대기"로 남고, 사용자가 `확인 완료`를 눌러야 지원금에 반영(`할인 안 됨`이면 삭제)
