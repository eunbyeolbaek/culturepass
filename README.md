# 청년문화패스 통합앱 프로토타입

청년국가재정마스터 5기 21팀 · 청년문화예술패스 분석 보고서 후속 프로토타입. 모든 공연·가격·쿠폰은 예시/참고 데이터이며, 본인 인증은 화면 예시입니다.

## 폴더 구성
| 경로 | 설명 |
|---|---|
| `index.html` | **배포용 단일 파일** (CSS·JS 포함). 이 파일만 있어도 동작해요 |
| `src/` | 개발용 분리 소스 (`index.html`, `style.css`, `data.js`, `app.js`) |

## GitHub Pages로 공개하기 (가장 간단한 방법)
1. 저장소 루트에 이 폴더 안의 파일을 그대로 올립니다 (폴더째가 아니라 **안에 있는 파일**을 올려요).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://계정명.github.io/저장소명/` 접속

## 로컬 실행
`index.html`을 더블클릭하거나 `python3 -m http.server 8000` 후 http://localhost:8000

## 데이터 수정
`src/data.js`의 공연 목록(`RAW`), 기준일(`TODAY`)을 고친 뒤 `src/` 내용을 합쳐 루트 `index.html`을 갱신하세요.
- `est:1` 항목은 요금을 확인하지 못한 예시가입니다.
- 좌석 항목 3번째 값(`{k,c,rg}`)은 앱에서 바로 적용하지 않는 할인 권종(재관람·지역 할인)입니다.
- 공연 정보는 2026-10-12 기준 공개 자료로 구성했어요. 일정·가격은 수시로 바뀝니다.

## 실서비스 전환 시 과제
예매처 API 연동 여부, 포인트 잔액 조회 방식, 주민등록 주소 확인(PASS는 주소 미제공), 기한 알림 계산, 영화 횟수 제한 표시, 상태 저장(localStorage/서버)
